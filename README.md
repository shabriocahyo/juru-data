# Juru Data

**Juru Data** is a web-based e-learning platform designed to train aspiring data professionals through structured courses, interactive modules, and mentor feedback. The application supports distinct user roles (Admin, Instructor, Student) and focuses on practical, project-oriented learning to help learners build real portfolios and job-ready skills.

---

## Key Features

- **Role-based Access**
  - Admin, Instructor, and Student roles with tailored dashboards and permissions.
- **Course & Module Management**
  - Create and organize classes, modules, and lessons with progress tracking.
- **Assignments & Reviews**
  - Students can submit assignments; instructors review work and provide feedback.
- **Articles & Testimonials**
  - Dynamic content pages for articles and participant reviews to share knowledge and success stories.
- **User Profiles & Certificates**
  - Viewable user profiles, course history, and downloadable certificates upon completion.
- **Simple Local Development Stack**
  - Developed for local deployment using VSCode, XAMPP (Apache + MySQL), and MySQL/MariaDB.

---

## Technologies

- Frontend: HTML, CSS, JavaScript (standard web stack)
- Backend: PHP (compatible with XAMPP)
- Database: MySQL / MariaDB
- Development tools: VSCode, XAMPP (for local server), phpMyAdmin (optional for DB management)
